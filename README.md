# AI RAG Engineering

A collection of hands-on projects exploring **AI Engineering, Retrieval-Augmented Generation (RAG), Large Language Models (LLMs), and Agentic AI**.

## Projects

### 01. RAG (Retrieval-Augmented Generation)

Exploring and building RAG-based applications, focusing on retrieving relevant context and enhancing LLM responses with external knowledge.

**Technologies:** Python, LLMs, Embeddings, Vector Databases

### 02. LangChain & ChromaDB – Document Vectorization

Building a document vectorization pipeline using LangChain, Hugging Face Sentence Transformers, and ChromaDB.

**Key concepts:**
- Document loading and processing
- Text splitting and chunking
- Vector embeddings
- Semantic representation of documents
- Vector storage and retrieval

**Technologies:** Python, LangChain, Hugging Face, Sentence Transformers, ChromaDB
