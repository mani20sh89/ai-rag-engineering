# AI RAG Engineering

A hands-on engineering portfolio exploring **Artificial Intelligence, Large Language Models (LLMs), Retrieval-Augmented Generation (RAG), vector databases, and intelligent AI applications**.

This repository documents practical implementations of modern AI engineering concepts, with a focus on building, experimenting with, and understanding production-oriented AI workflows.

---

## Projects

### 01. RAG (Retrieval-Augmented Generation)

Exploring the fundamentals of Retrieval-Augmented Generation and building applications that combine information retrieval with Large Language Models.

**Key concepts:**
- RAG architecture and workflows
- LLM integration
- Document retrieval
- Embeddings and vector search
- Context-aware generation

**Technologies:** Python, LLMs, Embeddings, Vector Databases

---

### 02. LangChain & ChromaDB – Document Vectorization

Implementation of a document vectorization pipeline using LangChain, Hugging Face Sentence Transformers, and ChromaDB.

The project focuses on converting unstructured documents into vector embeddings and storing them in a vector database for efficient semantic retrieval.

**Key concepts:**
- Document loading and processing
- Text splitting and chunking
- Vector embedding generation
- Hugging Face Sentence Transformers
- ChromaDB vector storage
- Semantic similarity search

**Technologies:** Python, LangChain, Hugging Face, Sentence Transformers, ChromaDB

---

### 03. InsureLLM – RAG Question Answering

Development of a retrieval-augmented question-answering application for InsureLLM.

The application retrieves relevant information from a persistent ChromaDB vector store and uses an LLM to generate context-aware responses through an interactive Gradio interface.

**Key concepts:**
- Retrieval-based question answering
- Semantic document retrieval
- Context-grounded LLM responses
- LangChain retriever integration
- Prompt engineering
- Interactive AI applications

**Technologies:** Python, LangChain, ChromaDB, Hugging Face, Sentence Transformers, OpenAI, Gradio
